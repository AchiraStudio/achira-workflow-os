# Achira OS V3

The blueprint for AI-native software engineering. A modular directory of 20 elite AI personas, 38 skill modules, and 14 automated workflows that you can install into any project with a single command.

## 🚀 Get Started

Install the Agentic OS directory using our official CLI tool published on npm:

```bash
# 1. Install the CLI globally
npm i achira-wf

# 2. Initialize the OS in your repository
npx achira-wf init
```

This command will:

- 📂 Provision the `.agent/` core directory
- 🤖 Install 20 specialist AI personas
- ⚡ Setup 38 domain-specific knowledge modules
- 🛠️ Configure 14 slash command workflows

## 🏗️ Architecture

Achira OS is designed to be highly modular and portable. Once initialized, the `.agent/` directory becomes the single source of truth for all AI-native interactions within your project.

### Core Components

- **Core**: The brain — agents, skills, and shared datasets.
- **Workflows**: Slash command procedures and discovery maps.
- **Rules**: Global AI constraints and behavioral modes.
- **Scripts**: Master validation & verification patterns.

## 🛠️ Tech Stack

- **Frontend**: React + Vite
- **Styling**: Vanilla CSS (Sapphire Glassmorphism)
- **Animations**: Framer Motion
- **Icons**: Lucide React
